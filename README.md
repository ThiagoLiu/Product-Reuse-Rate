# 物料复用率工具 V1.0.0

作者 [Thiago（@ThiagoLiu）](https://github.com/ThiagoLiu)

双击项目根目录里的“启动工具.cmd”运行当前版本。源码、运行环境和数据都在 `tool` 子目录里。关闭最后一个工具标签页后，程序通常在约 6 秒后退出。若浏览器异常关闭，则在最后一次页面报到约 90 秒后退出。

## 开始使用

1. 点击左侧“＋”新建分类，例如座椅、车架、排气。
2. 进入分类，点击“添加 / 更新项目”，可以一次选择多个 Excel 文件。左侧可搜索或滚动查找分类，右键点击分类名称可重命名或删除。
3. 每个Excel代表一个项目，批量导入按文件名匹配同名项目，并在预览中提示更新。若新版表格改了文件名，可在原项目旁选择“更新此项目”，不用新增项目。不同项目请使用不同名称。
4. 表头包含“子阶料号”和“借用件/新开件”，分类值必须为“借用件”或“新开件”。支持.xlsx。所有包含有效表头的工作表一起读取，预览列出各工作表的有效行数。空表跳过，非空但缺少表头的工作表会提示。
5. 核对预览后确认保存。相同文件不重复保存，更新保留旧版本，只用最新版本计算。打开“总览”，可查看按复用率排序的分类对比柱状图。

右键点击大分类可新建小分类。第一次新建时，已有直属项目自动归入该大分类的“未分组”。在项目列表中点“移动项目”，可把项目及历史版本移到同一大分类下的其他小分类。总览可切换大分类平均复用率和最小分类复用率两种排名。有结果的小分类等权参与大分类平均，暂无结果的分类不参与排名。没有小分类的大分类按自身项目计算。

## 统计规则

每个分类单独统计全部有效项目，季度不限制范围。跨项目重复编码：同一编码出现在至少两个不同项目中，只计1种；出现3次或50次仍只计1种。对应编码的所有借用件记录不再计入借用件数量。

复用率 =（跨项目重复编码种类数 + 排除重复编码后的借用件数量）÷（所有有效物料行数 − 跨项目重复编码种类数）。

分母为0显示暂无结果。单项目内部重复仅提示，保留原始行；不会仅凭内部重复认定为跨项目重复。物料编码区分大小写，清理首尾空格，其余内容保留。Excel中已因数字格式丢失的前导零无法自动恢复，编码应使用文本存储。

## 数据保存与删除

数据库位于 `tool/便携版/data/reuse.sqlite3`，完整保存物料明细及原始 Excel 文件副本。如果使用系统 Python 直接运行源码，默认数据库位于 `tool/data/reuse.sqlite3`。删除、移动或重命名外部 Excel 不会影响工具。

项目可单独或批量移入回收站，整个分类也可移入回收站，立即停止参与计算；恢复后重新参与。永久删除清除当前库中相关项目、版本和原表。自动备份及已经导出的迁移包不随永久删除修改。

## 换电脑与备份

在“备份与迁移”中导出迁移包，将程序和迁移包发给B电脑，启动后恢复迁移包。迁移包包含数据库中的全部数据，包括回收站和原始表格。恢复会完整替换B电脑当前数据库，不做合并，操作前自动备份。

自动备份位于data/backups，不会自动清理。若需从自动备份恢复：先退出程序，保留当前data/reuse.sqlite3副本，再把选定的备份复制为data/reuse.sqlite3，重新启动。也可在退出程序后直接复制整个工具文件夹迁移。

请将工具放在可写目录，避免放在Program Files等受保护目录。重复双击同一份工具会打开已运行的本地页面。迁移包和导出报表包含业务数据，请自行妥善保管。

## 源码运行与构建

在 `tool` 目录中使用 Python 3.11 及以上版本。安装 `requirements.txt` 中的依赖后运行 `python app.py`。测试运行 `python -m unittest -v test_app.py`，真实样表位于项目根目录旁的“座椅”文件夹。使用 Windows 64 位 Python 3.14 和系统自带的 .NET Framework C# 编译器运行 `python build_portable.py`，可生成“便携版”。

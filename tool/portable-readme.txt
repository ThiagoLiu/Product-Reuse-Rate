物料复用率工具 V1.0.0

1. 将压缩包完整解压到本机可写目录，例如“文档”。
2. 打开解压后的 ProductReuseRate 文件夹，双击 ProductReuseRate.exe。
3. 工具会自动打开浏览器。支持 64 位 Windows，无需另装 Python 或 Excel，可离线使用。
4. 关闭最后一个工具标签页后，程序通常在约 6 秒后退出。

录入与统计

在左侧点击“＋”新建大分类。右键点击大分类可新建小分类。进入最小分类后，点击“添加 / 更新项目”，选择一个或多个 .xlsx 文件。表格需包含“子阶料号”和“借用件/新开件”两列。

“总览”可切换按大分类或小分类查看柱状图。大分类的平均值按有结果的小分类等权计算。首次新建小分类时，已有直属项目会归入“未分组”，可通过“移动项目”重新归类。

备份与迁移

首次启动会在程序目录内生成 data 文件夹。工具压缩包不附带任何业务数据。若需迁入原电脑的数据，请同时拿到原电脑导出的迁移包，在“备份与迁移”中选择恢复。恢复会替换本机数据库，并先自动备份原有数据。
